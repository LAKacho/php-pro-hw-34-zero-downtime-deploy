# ДЗ 34. Автоматический zero-downtime deploy

Репозиторий содержит универсальный Bash-скрипт доставки Symfony/PHP-приложения и GitHub Actions workflow.

Новый релиз собирается отдельно, постоянные данные находятся в `shared`, конфигурация остаётся только на сервере, а активная версия переключается атомарной символьной ссылкой. При неуспешном healthcheck скрипт возвращает предыдущий релиз.

Подробная настройка и команды: [deploy/README.md](deploy/README.md).
